🎓 UniSolve – University Student Problem Reporting & Resolution Platform

Students Report. Universities Solve.

UniSolve is a web-based platform designed to help university students report campus-related problems and enable administrators to manage, track, and resolve them efficiently.

🚀 Project Overview

UniSolve provides a centralized platform where students can register campus problems, such as hostel maintenance, classroom issues, electrical problems, water supply, internet connectivity, and other social problems.

University administrators can access a dashboard to monitor reported issues and update their resolution status.

✨ Key Features

👨‍🎓 Student Module

- Submit campus-related problems.
- Enter student name, roll number, and college name.
- Select problem categories.
- Provide problem location and description.
- View recently submitted reports.
- Track problem status.

🛡️ Admin Module

- Multiple administrator login accounts.
- Separate Super Admin and Admin roles.
- View all reported problems.
- Dashboard with problem statistics.
- Filter problems by status.
- Update problem status:
  - Pending
  - In Progress
  - Resolved
- Super Admin-only problem deletion.

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Submit a student problem.
5. Use the Admin Login to access the dashboard.

🎯 Objective

To create a simple and effective digital platform that connects students and university administrators, improves communication, and helps universities identify and resolve campus problems systematically.

🔮 Future Enhancements

- Secure backend authentication.
- Database integration (MySQL / MongoDB).
- Student registration and login.

- Multiple university support.
- Real-time problem tracking.
- Cloud deployment with HTTPS.

⚠️ Current Limitations

This is a frontend demonstration project.

- Data is stored in browser LocalStorage.
- Reports are not shared between different users or devices.
- Admin credentials are stored in frontend JavaScript.
- Authentication is not secure enough for real-world deployment.

A backend, secure password hashing, server-side authorization, and a database are required before production use.
